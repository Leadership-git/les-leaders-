LEÇON 3 - TERMINALE A1

Résumé de texte et rédaction de texte argumentatif

Français — Méthode et rédaction

I. LE RÉSUMÉ DE TEXTE

Le résumé de texte consiste à reformuler de manière courte et fidèle les idées essentielles d'un texte.

Le résumé doit conserver la pensée de l'auteur tout en réduisant la longueur du texte.
Dans un résumé, il faut :

• Respecter les idées essentielles.

• Respecter l'ordre logique des idées.

• Reformuler avec ses propres mots.

• Respecter la longueur demandée.

• Rester fidèle au texte.

II. LIRE ET COMPRENDRE LE TEXTE

Avant de rédiger le résumé :

1. Lire attentivement le texte.

2. Identifier le thème.

3. Repérer les idées principales.

4. Repérer les idées secondaires.

5. Repérer les liens logiques entre les idées.

III. REFORMULER LES IDÉES

Le résumé ne consiste pas à recopier les phrases du texte.

Il faut reformuler les idées avec ses propres mots tout en conservant leur sens.
Exemple :

Idée du texte : « Les nouvelles technologies facilitent la communication entre les personnes éloignées. »

Reformulation possible : « Les technologies modernes permettent aux personnes éloignées de communiquer plus facilement. »

IV. CE QU'IL FAUT ÉVITER DANS UN RÉSUMÉ

Évite :

• Le copier-coller de phrases entières.

• Les commentaires personnels.

• Les exemples inutiles.

• Les répétitions.

• Les idées qui ne figurent pas dans le texte.

• Le non-respect de la longueur demandée.

V. LA RÉDACTION DU RÉSUMÉ

Après avoir identifié les idées essentielles et les avoir reformulées, il faut les organiser dans un texte cohérent.
COMPRENDRE → SÉLECTIONNER → REFORMULER → ORGANISER → RÉDIGER → RELIRE
Le résumé doit former un texte cohérent et correctement rédigé.

Les connecteurs logiques peuvent être utilisés pour conserver les relations entre les différentes idées.

VI. LE TEXTE ARGUMENTATIF

Un texte argumentatif est un texte dans lequel l'auteur défend une idée ou un point de vue.

Il cherche à convaincre ou à faire réfléchir le lecteur grâce à des arguments et des exemples.
THÈSE → ARGUMENTS → EXPLICATIONS → EXEMPLES → CONCLUSION

VII. LA THÈSE

La thèse est l'idée ou la position que l'on défend dans un texte argumentatif.
Exemple :

Sujet : « Faut-il encourager la lecture chez les jeunes ? »

Thèse possible : La lecture doit être encouragée chez les jeunes.

VIII. L'ARGUMENT

Un argument est une raison utilisée pour défendre une thèse.

Un bon argument doit être expliqué et, lorsque cela est possible, illustré par un exemple.
Exemple :

Thèse : La lecture est importante pour les jeunes.

Argument : Elle permet d'enrichir le vocabulaire.

Explication : La lecture expose le lecteur à de nombreux mots et à différentes façons de les employer.

Exemple : La lecture régulière de romans peut aider un élève à mieux maîtriser la langue.

IX. LES CONNECTEURS LOGIQUES

Les connecteurs logiques permettent d'organiser les idées et de montrer les relations entre elles.
Pour ajouter : de plus, ensuite, également.

Pour expliquer : en effet, parce que, puisque.

Pour donner une conséquence : donc, ainsi, par conséquent.

Pour opposer : cependant, toutefois, pourtant.

Pour conclure : enfin, en conclusion, finalement.

X. ORGANISER UN TEXTE ARGUMENTATIF

Introduction :

Présenter le sujet et annoncer la position défendue.

Développement :

Présenter les arguments, les expliquer et les illustrer.

Conclusion :

Faire le bilan et répondre clairement au sujet.

XI. MÉTHODE POUR LE BAC

Pour le résumé :

1. Lire et comprendre le texte.

2. Repérer les idées essentielles.

3. Supprimer les détails secondaires.

4. Reformuler les idées.

5. Respecter l'ordre logique.

6. Respecter la longueur demandée.

7. Relire.

Pour le texte argumentatif :

1. Comprendre le sujet.

2. Identifier la position à défendre.

3. Rechercher les arguments.

4. Chercher des exemples.

5. Organiser les idées.

6. Utiliser des connecteurs logiques.

7. Rédiger une conclusion.

8. Relire la copie.
