I. SYSTÈME DE 2 ÉQUATIONS

Résoudre :
{ ax + by = c
{ a'x + b'y = c'

Méthodes : Substitution ou Combinaison
Exemple :
{ 2x + y = 5
{ x - y = 1

Addition : 3x = 6 → x=2
Remplace : 2 - y =1 → y=1
S = {(2,1)}

II. PROGRAMMATION LINÉAIRE - Méthode BAC

Maximiser un bénéfice sous contraintes.
Étapes BAC :
1) Inconnues x et y
2) Contraintes : x≥0, y≥0, ax+by ≤ c...
3) Tracer les droites et trouver le polygone
4) Trouver les sommets du polygone
5) Calculer f(x,y) en chaque sommet, prendre le max/min
Exemple type BAC A1 :
P1 rapporte 3000F, P2 rapporte 5000F.
x ≥ 0 , y ≥ 0
x + y ≤ 10
2x + y ≤ 14

Sommets : O(0,0) , A(7,0) , B(4,6) , C(0,10)
Bénéfice B = 3000x + 5000y
B(O)=0
B(A)=21000
B(B)=42000
B(C)=50000 → MAX en C (0,10)
Il faut fabriquer 0 P1 et 10 P2.
