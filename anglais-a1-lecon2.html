LEÇON 2 - TERMINALE A1

CONDITIONALS

English Grammar

I. LES CONDITIONALS

Les conditionals permettent d'exprimer une condition et sa conséquence.

La proposition introduite par if présente la condition.
IF + CONDITION → CONSEQUENCE

II. CONDITIONAL TYPE 1

Le Type 1 exprime une condition réelle ou possible dans le présent ou le futur.
If + Present Simple → will + Verb
Exemple :

If I study hard, I will pass my exam.

If it rains, we will stay at home.
⚠️ Après if, on ne met généralement pas will dans le Type 1.

III. CONDITIONAL TYPE 2

Le Type 2 exprime une situation imaginaire, hypothétique ou peu probable dans le présent ou le futur.
If + Past Simple → would + Verb
Exemple :

If I had enough money, I would buy a new computer.

If she studied harder, she would succeed.

IV. CONDITIONAL TYPE 3

Le Type 3 exprime une condition irréelle dans le passé. Il permet souvent de parler d'une situation qui ne s'est pas réalisée.
If + Past Perfect → would have + Past Participle
Exemple :

If I had studied, I would have passed the exam.

If they had arrived earlier, they would have seen the teacher.

V. UNLESS

Unless signifie généralement « à moins que » ou « sauf si ». Il introduit une condition négative.
Unless + condition → conséquence
Exemple :

Unless you study, you will fail.

= If you do not study, you will fail.
⚠️ Évite normalement de mettre une autre négation juste après unless.

VI. PROVIDED THAT

Provided that signifie « à condition que ». Il exprime une condition nécessaire.
You can go out provided that you finish your homework.

= Tu peux sortir à condition que tu finisses tes devoirs.

VII. AS LONG AS

As long as signifie « tant que » ou « à condition que ».
You can use my computer as long as you take care of it.

= Tu peux utiliser mon ordinateur à condition d'en prendre soin.

VIII. TABLEAU RÉCAPITULATIF

Type 1 :
If + Present Simple → will + Verb

Situation réelle ou possible.

Type 2 :
If + Past Simple → would + Verb

Situation imaginaire ou peu probable.

Type 3 :
If + Past Perfect → would have + Past Participle

Situation irréelle dans le passé.

🧠 À RETENIR POUR LE BAC

Type 1 → possible

Type 2 → imaginaire / hypothétique

Type 3 → irréel dans le passé
