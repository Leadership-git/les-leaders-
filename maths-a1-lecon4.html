LEÇON 4 - TERMINALE A1/A2

Suites Numériques

Arithmétique et Géométrique - 5 points au BAC

I. DÉFINITION D'UNE SUITE NUMÉRIQUE

Une suite numérique est une liste de nombres réels notés U₀, U₁, U₂, U₃, ...

Chaque nombre de la suite est appelé un terme. On note généralement la suite (Uₙ).
Exemple :
U₀ = 2, U₁ = 5, U₂ = 8, U₃ = 11, ...

Les nombres 2, 5, 8 et 11 sont les premiers termes de la suite.
Une suite peut être définie de deux façons principales :

1. Par une relation de récurrence :
On connaît un premier terme et une relation permettant de calculer le terme suivant.

2. Par une formule explicite :
On donne directement Uₙ en fonction de n.

II. SUITE ARITHMÉTIQUE

Une suite (Uₙ) est arithmétique lorsqu'on obtient chaque terme en ajoutant toujours le même nombre r au terme précédent. r est appelé la raison de la suite.
Uₙ₊₁ = Uₙ + r
Pour trouver la raison :

r = Uₙ₊₁ - Uₙ

Si cette différence est constante, alors la suite est arithmétique.

Formule du terme général

Uₙ = U₀ + nr

ou

Uₙ = U₁ + (n - 1)r
Exemple :

U₀ = 2 et r = 3

U₁ = 2 + 3 = 5
U₂ = 5 + 3 = 8
U₃ = 8 + 3 = 11

Donc : Uₙ = 2 + 3n

III. SOMME DES TERMES D'UNE SUITE ARITHMÉTIQUE

Somme = Nombre de termes × (premier terme + dernier terme) ÷ 2
Exemple :

Calculons : S = U₀ + U₁ + ... + U₁₀

Il y a 11 termes. U₀ = 2 et U₁₀ = 32.

S = 11 × (2 + 32) ÷ 2

S = 11 × 17

S = 187

IV. SUITE GÉOMÉTRIQUE

Une suite (Uₙ) est géométrique lorsqu'on obtient chaque terme en multipliant toujours le terme précédent par le même nombre q. q est appelé la raison de la suite.
Uₙ₊₁ = Uₙ × q
Pour trouver la raison, lorsque les termes précédents sont non nuls :

q = Uₙ₊₁ ÷ Uₙ

Si ce quotient est constant, la suite est géométrique.

Formule du terme général

Uₙ = U₀ × qⁿ

ou

Uₙ = U₁ × qⁿ⁻¹
Exemple :

U₀ = 4 et q = 0,5

U₁ = 4 × 0,5 = 2
U₂ = 2 × 0,5 = 1
U₃ = 1 × 0,5 = 0,5

Donc : Uₙ = 4 × (0,5)ⁿ

V. SOMME DES TERMES D'UNE SUITE GÉOMÉTRIQUE

Si q ≠ 1 : S = U₀ × (1 - qⁿ⁺¹) ÷ (1 - q)
Exemple :

Calculons : S = U₀ + U₁ + U₂ + U₃ avec U₀ = 2 et q = 3.

Les termes sont : 2 ; 6 ; 18 ; 54

Donc : S = 2 + 6 + 18 + 54

S = 80

VI. SENS DE VARIATION

Pour une suite arithmétique :

Si r > 0 → la suite est croissante.
Si r < 0 → la suite est décroissante.
Si r = 0 → la suite est constante.

Pour une suite géométrique à termes positifs :

Si q > 1 → la suite est croissante.
Si 0 < q < 1 → la suite est décroissante.
Si q = 1 → la suite est constante.

VII. LIMITES DES SUITES GÉOMÉTRIQUES

Lorsque 0 < q < 1, les puissances qⁿ deviennent de plus en plus petites lorsque n augmente.

Ainsi : qⁿ → 0 lorsque n → +∞.
Exemple :

Uₙ = 4 × (0,5)ⁿ

Comme : 0 < 0,5 < 1

on a : Uₙ → 0 lorsque n → +∞.

VIII. RECONNAÎTRE UNE SUITE

Pour reconnaître une suite arithmétique :

On calcule : Uₙ₊₁ - Uₙ

Si le résultat est constant → suite arithmétique.

Pour reconnaître une suite géométrique :

On calcule : Uₙ₊₁ ÷ Uₙ

Si le résultat est constant → suite géométrique.

IX. PROBLÈME TYPE BAC

Une entreprise produit 1000 unités en 2020. Chaque année, sa production augmente de 50 unités.

On note Uₙ la production n années après 2020.

On a : U₀ = 1000 et r = 50.

La suite est donc arithmétique.

Son terme général est : Uₙ = 1000 + 50n

En 2026 : n = 6

U₆ = 1000 + 50 × 6

U₆ = 1300 unités.
