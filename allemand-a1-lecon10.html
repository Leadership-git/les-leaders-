LEÇON 10 — RELATIVSÄTZE

🎯 Lernziel — Objectif

Dans cette leçon, nous allons découvrir les Relativsätze, c'est-à-dire les propositions relatives en allemand.

L'objectif est de savoir reconnaître une proposition relative et utiliser les pronoms relatifs simples der, die, das.

1️⃣ Was ist ein Relativsatz?

Un Relativsatz donne une information supplémentaire sur une personne, un animal ou une chose mentionnée dans la proposition principale.

Nom + pronom relatif + ... + verbe à la fin

Das ist der Mann, der dort steht.

C'est l'homme qui se tient là-bas.


Das ist die Frau, die Deutsch spricht.

C'est la femme qui parle allemand.

2️⃣ Die Relativpronomen

Les pronoms relatifs les plus simples correspondent aux articles définis :

Genre Pronom Français
Masculin der qui / que
Féminin die qui / que
Neutre das qui / que
Pluriel die qui / que

3️⃣ „der“ — Masculin

On utilise der pour reprendre un nom masculin lorsque le pronom relatif est sujet de la proposition.

Der Mann, der dort steht, ist mein Lehrer.

L'homme qui se tient là-bas est mon professeur.


Der Schüler, der Deutsch lernt, ist fleißig.

L'élève qui apprend l'allemand est travailleur.

4️⃣ „die“ — Féminin

On utilise die pour reprendre un nom féminin lorsque le pronom relatif est sujet.

Die Frau, die dort sitzt, ist meine Mutter.

La femme qui est assise là-bas est ma mère.


Die Schülerin, die Deutsch spricht, ist nett.

L'élève qui parle allemand est gentille.

5️⃣ „das“ — Neutre

On utilise das pour reprendre un nom neutre lorsque le pronom relatif est sujet.

Das Buch, das dort liegt, ist interessant.

Le livre qui est là-bas est intéressant.


Das Kind, das spielt, ist glücklich.

L'enfant qui joue est heureux.

6️⃣ „die“ — Plural

Au pluriel, le pronom relatif sujet est également die.

Die Schüler, die Deutsch lernen, sind motiviert.

Les élèves qui apprennent l'allemand sont motivés.


Die Bücher, die hier liegen, sind neu.

Les livres qui sont ici sont nouveaux.

7️⃣ Die Wortstellung

Comme dans les autres propositions subordonnées, le verbe conjugué se place à la fin du Relativsatz.

Der Mann, der Deutsch spricht, ist Lehrer.

Relativsatz : der Deutsch spricht

Le verbe spricht est placé à la fin.

📊 Übersicht — Résumé

Nom Relatif Exemple
der Mann der Der Mann, der kommt...
die Frau die Die Frau, die kommt...
das Kind das Das Kind, das kommt...
die Schüler die Die Schüler, die kommen...

📖 Textverständnis

Das ist mein Freund, der in Abidjan lebt. Er hat eine Schwester, die Deutsch lernt. Sie hat ein Buch, das sehr interessant ist. Die Schüler, die Deutsch lernen, machen gute Fortschritte.


Dans ce texte, on trouve plusieurs pronoms relatifs : der, die et das.

📝 Übungen — Exercices

1. Der Mann, ___ dort steht, ist mein Lehrer.
a) der    b) die    c) das
2. Die Frau, ___ Deutsch spricht, ist meine Lehrerin.
a) der    b) die    c) das
3. Das Buch, ___ dort liegt, ist neu.
a) der    b) die    c) das
4. Die Schüler, ___ Deutsch lernen, sind motiviert.
a) der    b) die    c) das
5. Complète :
Der Schüler, ___ Deutsch spricht, ist intelligent.
a) der    b) die    c) das
6. Complète :
Die Lehrerin, ___ dort steht, ist freundlich.
a) der    b) die    c) das
7. Mets les mots dans l'ordre :
der / Mann / kommt / Der / ist / Lehrer

🧠 Wiederholung — À retenir

🔵 der → masculin

🟢 die → féminin

🟠 das → neutre

🟣 die → pluriel


Règle importante : dans le Relativsatz, le verbe conjugué se place à la fin.


Der Mann, der Deutsch spricht, ist mein Lehrer.
