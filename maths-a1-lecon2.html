LEÇON 2 - TERMINALE A1

Fonction Logarithme Népérien ln

Leçon la plus importante du BAC (8 points)

I. DÉFINITION ET ENSEMBLE DE DÉFINITION

Définition : La fonction ln est définie sur ]0 ; +∞[
On a : ln(1) = 0 et ln(e) = 1
e ≈ 2,718
ATTENTION BAC : ln(x) n'existe QUE si x > 0.
Toujours commencer par : Il faut x > 0 donc Df = ]0;+∞[

II. PROPRIÉTÉS FONDAMENTALES (QCM)

1) ln(a × b) = ln a + ln b
2) ln(a / b) = ln a - ln b
3) ln(a^n) = n × ln a
4) ln(1/a) = -ln a
5) ln(e^x) = x et e^(ln x) = x
Exemples :
ln(e²) = 2×ln e = 2×1 = 2
ln(1) = ln(e^0) = 0
ln(1/e) = -ln e = -1
ln(√e) = ln(e^1/2) = 1/2
QCM BAC 2025 :
Résoudre ln x ≤ 0
→ ln x ≤ ln 1
→ x ≤ 1 et x > 0
→ S = ]0 ; 1]

III. DÉRIVÉE ET VARIATIONS

Définition dérivée :
(ln x)' = 1/x sur ]0;+∞[
(ln u)' = u' / u à condition que u > 0
Propriété variations :
La fonction ln est strictement croissante sur ]0;+∞[
Donc :
ln a < ln b ⇔ a < b
ln a = ln b ⇔ a = b (avec a>0, b>0)
Exercice dérivée :
f(x) = ln(x²+1)
u = x²+1 → u' = 2x
f'(x) = u'/u = 2x / (x²+1)

f(x) = ln x + x
f'(x) = 1/x + 1 = (1+x)/x

IV. ÉQUATIONS ET INÉQUATIONS (Exercice BAC 2010)

Méthode :
1) Chercher Df (x>0)
2) Mettre sous forme ln a = ln b
3) Enlever ln : a = b

Exemple BAC tombé :
Résoudre 2(ln x)³ -7(ln x)² -5 ln x +4 =0

On pose X = ln x
On obtient 2X³-7X²-5X+4=0
On trouve X = -1 , X=1/2 , X=4

Donc :
ln x = -1 → x = e^-1 = 1/e
ln x = 1/2 → x = e^1/2 = √e
ln x = 4 → x = e^4

S = {1/e ; √e ; e^4}

V. LIMITES DE ln

lim ln x = -∞ quand x→0+
lim ln x = +∞ quand x→+∞
lim (ln x)/x = 0 quand x→+∞
lim x×ln x = 0 quand x→0+
Si lim f(x) = -∞ en 0+ → x=0 est asymptote verticale
