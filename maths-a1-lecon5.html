LEÇON 5 - TERMINALE A1/A2

Statistique à 2 variables

Nuage de points • Droite de Mayer • Corrélation

I. SÉRIE STATISTIQUE À 2 VARIABLES

Une série statistique à deux variables associe à chaque individu deux valeurs notées généralement x et y.

On représente les données sous la forme de couples :

(x₁ ; y₁), (x₂ ; y₂), ..., (xₙ ; yₙ)
Exemple :

On étudie l'évolution du nombre d'élèves inscrits dans une formation.

x représente l'année et y le nombre d'élèves.

On peut obtenir les couples :

(2021 ; 120), (2022 ; 135), (2023 ; 150)

II. NUAGE DE POINTS

Dans un repère, chaque couple (xᵢ ; yᵢ) est représenté par un point de coordonnées (xᵢ ; yᵢ).

L'ensemble de ces points constitue le nuage de points associé à la série statistique.
Le nuage de points permet d'observer graphiquement une éventuelle relation entre les deux variables.

Si les points semblent suivre une direction générale, on peut rechercher un ajustement affine.
À retenir :

Un nuage de points peut être :

• approximativement croissant ;
• approximativement décroissant ;
• ou sans tendance particulière.

III. POINT MOYEN

Le point moyen du nuage de points est le point dont les coordonnées sont les moyennes des coordonnées des points du nuage.

On le note généralement G.
G( x̄ ; ȳ )

x̄ = (x₁ + x₂ + ... + xₙ) / n

ȳ = (y₁ + y₂ + ... + yₙ) / n
Exemple :

On considère les valeurs :

x : 1 ; 2 ; 3 ; 4
y : 2 ; 4 ; 5 ; 9

Alors :

x̄ = (1+2+3+4)/4 = 2,5

ȳ = (2+4+5+9)/4 = 5

Donc le point moyen est : G(2,5 ; 5)

IV. DROITE DE MAYER

La droite de Mayer est une droite d'ajustement obtenue à partir du nuage de points.

Elle permet de représenter approximativement la tendance du nuage.
Pour déterminer la droite de Mayer :

1. On partage la série statistique en deux groupes de même effectif lorsque cela est possible.

2. On calcule le point moyen de chaque groupe.

3. On détermine l'équation de la droite passant par les deux points moyens.

V. ÉQUATION D'UNE DROITE

Une droite non verticale peut s'écrire sous la forme :
y = ax + b
a est le coefficient directeur.

b est l'ordonnée à l'origine.

Si on connaît deux points A(x₁ ; y₁) et B(x₂ ; y₂), avec x₁ ≠ x₂ :
a = (y₂ - y₁) / (x₂ - x₁)

b = y₁ - ax₁
Exemple :

A(1 ; 3) et B(3 ; 7)

a = (7-3)/(3-1)

a = 2

Donc : y = 2x + b

Avec A : 3 = 2×1 + b

b = 1

L'équation est donc : y = 2x + 1

VI. AJUSTEMENT AFFINE

Un ajustement affine consiste à rechercher une droite qui représente au mieux la tendance générale du nuage de points.

Son équation est de la forme :
y = ax + b
Si a > 0, la tendance est globalement croissante.

Si a < 0, la tendance est globalement décroissante.

Si a est proche de 0, la relation linéaire est faible.

VII. CORRÉLATION LINÉAIRE

La corrélation linéaire permet de mesurer l'intensité de la relation linéaire entre deux variables statistiques.

Elle est étudiée à l'aide du coefficient de corrélation linéaire, noté généralement r.
-1 ≤ r ≤ 1
Lorsque r est proche de 1, la corrélation linéaire positive est forte.

Lorsque r est proche de -1, la corrélation linéaire négative est forte.

Lorsque r est proche de 0, la corrélation linéaire est faible ou inexistante.

VIII. INTERPRÉTATION DU COEFFICIENT

Exemple 1 :

r = 0,95

Le coefficient est proche de 1.

On peut donc considérer qu'il existe une forte corrélation linéaire positive.

Les deux variables ont tendance à évoluer dans le même sens.
Exemple 2 :

r = -0,92

Le coefficient est proche de -1.

Il existe une forte corrélation linéaire négative.

Lorsque l'une des variables augmente, l'autre a tendance à diminuer.

IX. ESTIMATION À L'AIDE D'UNE DROITE

Une fois l'équation d'une droite d'ajustement obtenue, elle peut être utilisée pour effectuer des estimations.
Exemple :

On obtient la droite : y = 15x + 20

Pour x = 10 :

y = 15×10 + 20

y = 170

La valeur estimée de y est donc 170.

X. MÉTHODE POUR LE BAC

Étape 1 : Identifier les deux variables x et y.

Étape 2 : Placer les points dans un repère.

Étape 3 : Déterminer le point moyen si nécessaire.

Étape 4 : Construire la droite de Mayer lorsque la question le demande.

Étape 5 : Déterminer l'équation de la droite.

Étape 6 : Interpréter la corrélation.

Étape 7 : Utiliser la droite pour effectuer une estimation si nécessaire.
