LEÇON 6 - TERMINALE A1

Systèmes linéaires et programmation linéaire

Mathématiques — Niveau BAC A1

I. SYSTÈME LINÉAIRE

Un système linéaire est un ensemble de plusieurs équations dans lesquelles les inconnues sont au premier degré.

Dans cette leçon, on étudie notamment les systèmes de deux équations à deux inconnues.
ax + by = c
a'x + b'y = c'
Exemple :

Résoudre le système :

2x + y = 7
x - y = 2

On additionne les deux équations :

3x = 9

Donc : x = 3

Puis : x - y = 2

3 - y = 2

y = 1

La solution est donc : (x ; y) = (3 ; 1)

II. MÉTHODE PAR SUBSTITUTION

La méthode par substitution consiste à exprimer une inconnue en fonction de l'autre, puis à remplacer cette expression dans la deuxième équation.
Exemple :

x + y = 5
2x - y = 4

De la première équation : y = 5 - x

On remplace y dans la deuxième :

2x - (5 - x) = 4

2x - 5 + x = 4

3x = 9

x = 3

Donc : y = 5 - 3

y = 2

III. MÉTHODE PAR COMBINAISON

La méthode par combinaison consiste à multiplier éventuellement les équations puis à les additionner ou les soustraire afin d'éliminer une inconnue.
Exemple :

2x + y = 7
x - y = 2

En additionnant les deux équations :

3x = 9

Donc : x = 3

Puis : y = 1

IV. INTERPRÉTATION GRAPHIQUE

Une équation du premier degré à deux inconnues peut être représentée par une droite dans un repère.

Résoudre un système revient à rechercher les coordonnées du point d'intersection des deux droites.
Si les deux droites se coupent en un point, le système possède une solution unique.

Si les deux droites sont parallèles et distinctes, le système n'a aucune solution.

Si les deux droites sont confondues, le système possède une infinité de solutions.

V. INÉGALITÉS LINÉAIRES

Une inégalité linéaire est une inégalité dans laquelle les inconnues sont au premier degré.
ax + by ≤ c

ax + by ≥ c
Exemple :

On considère : x + y ≤ 6

Cette inégalité représente un demi-plan délimité par la droite : x + y = 6

VI. SYSTÈME D'INÉGALITÉS

Un système d'inégalités est constitué de plusieurs inégalités qui doivent être vérifiées simultanément.
Exemple :

x ≥ 0
y ≥ 0
x + y ≤ 6

La solution correspond à la région du plan qui vérifie simultanément les trois conditions.

VII. PROGRAMMATION LINÉAIRE

La programmation linéaire consiste à rechercher le maximum ou le minimum d'une expression linéaire sous certaines contraintes.
F(x,y) = ax + by
Dans un problème de programmation linéaire, on doit généralement :

1. Définir les inconnues.
2. Traduire les contraintes par des inégalités.
3. Représenter graphiquement la région admissible.
4. Déterminer les sommets de cette région.
5. Calculer la valeur de la fonction objectif aux sommets.
6. Choisir la valeur maximale ou minimale demandée.

VIII. PROBLÈME TYPE BAC

Une entreprise fabrique deux produits A et B.

On note : x = nombre de produits A
y = nombre de produits B

Les contraintes sont :

x ≥ 0
y ≥ 0
x + y ≤ 10

Le bénéfice est donné par :

F(x,y) = 300x + 200y

Il faut rechercher les valeurs de x et y qui permettent d'obtenir le bénéfice maximal dans la région autorisée.

IX. À RETENIR POUR LE BAC

Système : plusieurs équations à résoudre simultanément.

Substitution : exprimer une inconnue puis remplacer.

Combinaison : éliminer une inconnue par addition ou soustraction.

Programmation linéaire : optimiser une fonction sous contraintes.

Fonction objectif : expression que l'on cherche à maximiser ou à minimiser.
