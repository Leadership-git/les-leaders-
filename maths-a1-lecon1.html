LEÇON 1 - TERMINALE A1

Généralités sur les fonctions : Limites - Continuité - Dérivation

Cours officiel complet

I. LIMITES

Définition 1 : Limite en un point

Soit f une fonction et a un réel.
On dit que lim f(x) = L quand x→a si f(x) devient très proche de L quand x devient très proche de a.

Définition 2 : Limite à l'infini

lim f(x) = +∞ quand x→+∞ signifie que f(x) devient aussi grande qu'on veut quand x devient très grand.

Propriétés (Opérations)

Si lim f = l et lim g = l' alors :
- lim (f + g) = l + l'
- lim (f × g) = l × l'
- lim (f / g) = l / l' si l' ≠ 0

4 formes indéterminées à retenir pour le BAC :
0/0 ; ∞/∞ ; ∞ - ∞ ; 0 × ∞ → Il faut factoriser.

Limites de référence BAC A1

lim 1/x = 0 (x→+∞)
lim ln x = -∞ (x→0+) et +∞ (x→+∞)
lim e^x = 0 (x→-∞) et +∞ (x→+∞)

II. CONTINUITÉ ET ASYMPTOTE

Définition : Continuité

f est continue en a si :
1) f(a) existe
2) lim f(x) quand x→a existe
3) lim f(x) = f(a)

Définition : Asymptote verticale

Si lim f(x) = +∞ ou -∞ quand x→a,
alors la droite x = a est asymptote verticale.
Propriété BAC :
- Toute fonction dérivable est continue.
- Les fonctions polynômes, ln, exp sont continues sur leur domaine.

III. DÉRIVATION

Définition 1 : Nombre dérivé

f est dérivable en a si lim [f(x)-f(a)]/(x-a) existe. Cette limite est f'(a). C'est le coefficient directeur de la tangente.

Propriétés de dérivation

(u+v)' = u' + v'
(k.u)' = k.u'
(u×v)' = u'v + uv'
(1/u)' = -u' / u²
(u/v)' = (u'v - uv') / v²

Dérivées usuelles A1

(ln x)' = 1/x sur ]0;+∞[
(e^x)' = e^x
(ln u)' = u' / u si u>0
(e^u)' = u' × e^u

Propriété : Sens de variation

Si f'(x) > 0 sur I, alors f est croissante sur I.
Si f'(x) < 0 sur I, alors f est décroissante sur I.
Si f'(x) = 0, on a un maximum ou minimum.

IV. EXEMPLE PRATIQUE COMPLET (BAC)

On donne f(x) = ln x + x - 2 sur ]0;+∞[

1) Limites :
- En 0+ : lim ln x = -∞ donc lim f = -∞ → x=0 est asymptote verticale
- En +∞ : lim ln x = +∞ et lim x = +∞ donc lim f = +∞

2) Dérivée :
f'(x) = 1/x + 1 = (1+x)/x
Sur ]0;+∞[, x>0 donc f'(x) > 0

3) Variation :
f'(x) > 0 donc f est strictement croissante sur ]0;+∞[

4) Tableau :
x | 0 ............ +∞
f' | + + + + + + + +
f | -∞ ↗ +∞

C'est toujours ça au BAC ! Limite → Dérivée → Tableau.
