LEÇON 8 - TERMINALE A1/A2

Dénombrement et Probabilités

Mathématiques — Niveau BAC A1

I. RAPPELS SUR LE DÉNOMBREMENT

Le dénombrement permet de déterminer le nombre de possibilités dans une situation donnée.

Il est particulièrement utile dans les problèmes de probabilités lorsqu'on doit compter les cas possibles et les cas favorables.
Principe multiplicatif :

Si une première étape peut être réalisée de n façons et une deuxième de p façons, alors les deux étapes peuvent être réalisées de :

n × p

façons.
Exemple :

Un élève possède 3 chemises et 4 pantalons.

Nombre de tenues possibles : 3 × 4 = 12

Il peut donc former 12 tenues différentes.

II. FACTORIELLE

Pour tout entier naturel n non nul :

n! = n × (n-1) × (n-2) × ... × 2 × 1

Par convention : 0! = 1
Exemple :

5! = 5 × 4 × 3 × 2 × 1

5! = 120

III. ARRANGEMENTS

Un arrangement de p éléments parmi n est un choix de p éléments distincts parmi n éléments lorsque l'ordre compte.
A(n,p) = n! / (n-p)!
Exemple :

On choisit un président et un secrétaire parmi 5 élèves.

L'ordre compte car les deux fonctions sont différentes.

A(5,2) = 5! / 3!

A(5,2) = 20

IV. COMBINAISONS

Une combinaison de p éléments parmi n est un choix de p éléments distincts parmi n éléments lorsque l'ordre ne compte pas.
C(n,p) = n! / [p!(n-p)!]
Propriétés :

C(n,0) = 1
C(n,1) = n
C(n,n) = 1
C(n,p) = C(n,n-p)
Exemple :

On choisit 2 élèves parmi 8 élèves.

L'ordre ne compte pas.

C(8,2) = 8! / (2! × 6!)

C(8,2) = 28

V. EXPÉRIENCE ALÉATOIRE

Une expérience aléatoire est une expérience dont le résultat ne peut pas être prévu avec certitude avant sa réalisation.

L'ensemble de tous les résultats possibles est appelé univers et est noté généralement Ω.

Un événement est un ensemble de résultats de l'univers.
Exemple :

On lance un dé équilibré à six faces.

L'univers est : Ω = {1 ; 2 ; 3 ; 4 ; 5 ; 6}

L'événement A : « obtenir un nombre pair » est : A = {2 ; 4 ; 6}

VI. PROBABILITÉ D'UN ÉVÉNEMENT

La probabilité d'un événement A est un nombre compris entre 0 et 1.
0 ≤ P(A) ≤ 1
Lorsque les issues sont équiprobables :

P(A) = Nombre de cas favorables / Nombre de cas possibles
Exemple :

On lance un dé équilibré.

Événement A : « obtenir un nombre pair ».

Il y a 3 résultats favorables sur 6 résultats possibles.

P(A) = 3/6 = 1/2

VII. ÉVÉNEMENT CONTRAIRE

L'événement contraire de A, noté Ā, est l'événement qui se réalise lorsque A ne se réalise pas.
P(Ā) = 1 - P(A)
Exemple :

Si : P(A) = 0,3

Alors : P(Ā) = 1 - 0,3

P(Ā) = 0,7

VIII. UNION ET INTERSECTION

L'événement A ∩ B signifie que A et B se réalisent simultanément.

L'événement A ∪ B signifie que A ou B se réalise.
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
Si A et B sont incompatibles, alors :

P(A ∩ B) = 0

et donc :

P(A ∪ B) = P(A) + P(B)

IX. TIRAGE DE BOULES

Un sac contient 5 boules rouges et 3 boules noires.

On tire simultanément 2 boules.

Nombre total de tirages :

C(8,2) = 28

Probabilité d'obtenir 2 boules rouges :

P = C(5,2) / C(8,2)

P = 10/28 = 5/14

X. « AU MOINS UN »

Pour calculer la probabilité d'obtenir au moins un élément, on peut utiliser l'événement contraire :

P(au moins un) = 1 - P(aucun)
Dans le sac précédent :

P(au moins une boule rouge)

= 1 - P(aucune boule rouge)

= 1 - C(3,2) / C(8,2)

= 1 - 3/28

= 25/28

XI. MÉTHODE POUR LE BAC

Étape 1 : Identifier l'expérience aléatoire.

Étape 2 : Déterminer les résultats possibles.

Étape 3 : Déterminer les cas favorables.

Étape 4 : Choisir la formule adaptée.

Étape 5 : Effectuer le calcul et simplifier le résultat.

🧠 À RETENIR POUR LE BAC

Arrangement : l'ordre compte.

Combinaison : l'ordre ne compte pas.

Probabilité : P(A) = cas favorables / cas possibles.

Événement contraire : P(Ā) = 1 - P(A).

Union : P(A ∪ B) = P(A) + P(B) - P(A ∩ B).

Au moins un : P(au moins un) = 1 - P(aucun).
