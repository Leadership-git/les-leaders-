LEÇON 8 - TERMINALE A1

COMPARATIVES / SUPERLATIVES

Comparing people, things and situations

I. DÉFINITION

Le comparatif permet de comparer deux personnes, deux choses ou deux situations.

Le superlatif permet de présenter une personne, une chose ou une situation comme étant au plus haut ou au plus bas niveau dans un groupe.

II. COMPARATIF DE SUPÉRIORITÉ

Pour les adjectifs courts, on utilise généralement :

adjective + -er + than

Pour les adjectifs plus longs, on utilise :

more + adjective + than
John is taller than Peter.

This book is more interesting than that one.

English is easier than some languages.

III. COMPARATIF D'ÉGALITÉ

Pour dire que deux personnes ou deux choses ont le même degré d'une qualité :
as + adjective + as
John is as tall as Peter.

This exercise is as difficult as the previous one.

IV. COMPARATIF D'INFÉRIORITÉ

Pour exprimer l'infériorité, on utilise :
less + adjective + than
This exercise is less difficult than the previous one.

My car is less expensive than yours.

V. SUPERLATIF DE SUPÉRIORITÉ

Pour les adjectifs courts, on utilise généralement :

the + adjective + -est

Pour les adjectifs longs :

the most + adjective
John is the tallest student in the class.

This is the most interesting book.

VI. SUPERLATIF D'INFÉRIORITÉ

Pour exprimer le degré le plus faible :
the least + adjective
This is the least expensive car.

It is the least difficult exercise.

VII. RÈGLES D'ORTHOGRAPHE

Pour certains adjectifs courts :

tall → taller → the tallest

large → larger → the largest

happy → happier → the happiest

big → bigger → the biggest

VIII. ADJECTIFS IRRÉGULIERS

good → better → the best

bad → worse → the worst

far → farther / further → the farthest / the furthest
English is better than before.

She is the best student in the class.

Today is worse than yesterday.

IX. TABLEAU RÉCAPITULATIF

Supériorité :
taller than / more interesting than

Égalité :
as tall as / as interesting as

Infériorité :
less tall than / less interesting than

Superlatif :
the tallest / the most interesting

Superlatif d'infériorité :
the least interesting

📝 EXERCICES TYPE BAC

1. Mary is ______ than Jane. (tall)

Réponse : taller

2. This is ______ book in the library. (interesting)

Réponse : the most interesting

3. John is ______ Peter. (as / tall)

Réponse : as tall as

4. Mathematics is ______ than English for him. (difficult)

Réponse : more difficult

🧠 À RETENIR POUR LE BAC

-ER + THAN → comparatif avec adjectif court.

MORE + ADJECTIVE + THAN → comparatif avec adjectif long.

AS + ADJECTIVE + AS → égalité.

LESS + ADJECTIVE + THAN → infériorité.

THE -EST → superlatif avec adjectif court.

THE MOST + ADJECTIVE → superlatif avec adjectif long.
