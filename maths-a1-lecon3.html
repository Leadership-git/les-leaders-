LEÇON 3 - TERMINALE A1

Fonction Exponentielle exp

6 points au BAC

I. DÉFINITION

Définition : La fonction exp est définie sur R par f(x) = e^x
Elle est l'inverse de ln :
e^(ln x) = x si x>0
ln(e^x) = x
e^0 = 1
e^1 = e ≈ 2,718
e^x > 0 pour tout x

II. PROPRIÉTÉS (QCM BAC)

e^(a+b) = e^a × e^b
e^(a-b) = e^a / e^b
e^(-a) = 1 / e^a
(e^a)^n = e^(a×n)
Exemples :
e^2 × e^3 = e^5
e^5 / e^2 = e^3
1 / e^2 = e^-2

III. DÉRIVÉE ET VARIATIONS

Dérivée :
(e^x)' = e^x
(e^u)' = u' × e^u
Variation :
e^x est strictement croissante sur R
Et e^x > 0 toujours, donc pas de problème de domaine.
Exercice dérivée :
f(x) = e^(2x+1)
u = 2x+1 → u' = 2
f'(x) = 2 × e^(2x+1)

f(x) = e^x + x
f'(x) = e^x + 1 > 0 donc croissante

IV. ÉQUATIONS ET INÉQUATIONS

Règle :
e^a = e^b ⇔ a = b
e^a < e^b ⇔ a < b (car croissante)

Exemple 1 : e^x = 5 → x = ln 5
Exemple 2 : e^(2x) = e^3 → 2x=3 → x=3/2
Exemple 3 BAC : e^x ≤ 1 → e^x ≤ e^0 → x ≤ 0 → S = ]-∞;0]

V. LIMITES DE exp

lim e^x = 0 quand x→-∞
lim e^x = +∞ quand x→+∞
lim e^x / x = +∞ quand x→+∞
lim x×e^x = 0 quand x→-∞

VI. EXEMPLE COMPLET BAC

f(x) = e^x - x sur R

1) Limites :
En -∞ : e^x→0 et -x→+∞ donc f→+∞
En +∞ : e^x/x → +∞ donc f→+∞

2) Dérivée :
f'(x) = e^x - 1
f'(x)=0 ⇔ e^x=1 ⇔ x=0
f'(x)>0 ⇔ e^x>1 ⇔ x>0

3) Tableau :
x | -∞ .... 0 .... +∞
f'| - - - 0 + + +
f | +∞ ↘ 1 ↗ +∞
Minimum en 0 : f(0)=1
